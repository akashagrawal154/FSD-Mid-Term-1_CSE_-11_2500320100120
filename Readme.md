# Library Management System

This is a simple Library Management System developed using Node.js and Express.js. It allows users to add new books, view all books, search books by ID, update book details, and delete books. It also provides the option to issue and return book copies. The project uses in-memory storage with JavaScript arrays, so no database is required. All API requests can be tested using Postman. The server runs on port 3000.

To run the project, first install the required dependencies using `npm install` and then start the server using `node server.js`. After starting the server, the API can be accessed at `http://localhost:3000`.

Note: All data is stored temporarily and will be lost when the server is restarted.
